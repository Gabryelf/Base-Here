## 1. Концепция

Пошаговая стратегия в сеттинге корпоративного пост-апокалипсиса. Мировые
правительства пали, власть захвачена корпорациями. Крупнейшая корпорация —
**Гегемон** — управляется совершенным ИИ и стремится к полному контролю над
планетой. Человечество выживает в разрозненных эрзац-государствах и частных
компаниях.

Игрок — глава одной из таких фракций. Цель — объединить разрозненные силы
человечества и бросить вызов Гегемону.

## 2. Игровые режимы

Игра состоит из трёх взаимосвязанных режимов, каждый со своим канвасом
и собственной логикой.

### 2.1 Стратегический режим (Глобальная карта)
- Сетка **гексов**, пошаговый режим.
- Захват/оборона локаций.
- Расчёт ресурсов, найм и формирование групп войск.
- Выбор ячеек под застройку.
- Точка входа во все остальные режимы.

### 2.2 Тактический режим (Бой за локацию)
- Сетка **квадратов**, пошаговый режим.
- Управление выделенной группой войск.
- Победа/поражение возвращает результат в стратегический слой.

### 2.3 Строительный режим (Развитие локации)
- Отдельный канвас, привязанный к конкретной ячейке стратегической карты.
- Ограниченное количество слотов под застройку на локации.
- Каждый слот имеет тип/бонусы, постройки привязаны к типам слотов.
- Комбинированные постройки (синергии за определённые наборы).

## 3. Технические требования

- **Модульный JavaScript** (`<script type="module">`), без сборщика.
- **Один HTML-файл** как точка входа, стили подключаются модулями
  (или через `<style>` в отдельных модулях-компонентах).
- Работа через локальный сервер: `npx serve`.
- **Канвасы на весь экран устройства**, адаптация под портрет/ландшафт.
- Управление камерой (пан/зум) должно быть удобно на тач-устройствах
  и на десктопе.
- Спрайты — по мере появления, сейчас допустимо использовать
  примитивы (заливка гексов, квадратов, простые фигуры).
- **Профессиональная модульная архитектура**: чёткое разделение
  на слои (ядро, рендер, логика, данные, UI).

## 4. Архитектурные принципы

- **Ядро (Core)**: игровой цикл, менеджер состояний, шина событий,
  загрузка ассетов, утилиты.
- **Состояние (State)**: единое дерево игры, сериализуемое.
- **Режимы (Modes)**: `StrategyMode`, `TacticalMode`, `BuildMode` —
  взаимозаменяемые модули, реализующие общий интерфейс.
- **Рендер (Render)**: изолирован от логики, работает через адаптеры
  канваса. Камера — общий инструмент.
- **Ввод (Input)**: единый слой, транслирующий события мыши/тача/клавиатуры
  в игровые команды.
- **UI**: HTML-оверлей поверх канваса, управляемый через события ядра.
- **События**: слабая связность через EventBus.
